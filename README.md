# artificial-intelligence-programming-notes

Hand-typed study notes for Perry Xiao's *Artificial Intelligence Programming with Python: From Zero to Hero*.

See [`docs/README.md`](docs/README.md) for the workflow and [`docs/plan.md`](docs/plan.md) for the roadmap.

## Quick start

```bash
python -m venv .venv             # uses pyenv-resolved Python 3.10
source .venv/bin/activate
pip install --upgrade pip
pip install -e ".[dev]"
```

Start a new chapter with the `/new-chapter` slash command in Claude Code.
