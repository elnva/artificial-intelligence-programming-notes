## Conventions

- Stage numbers always two digits (`01`, `02`, …).
- Slugs are lowercase, hyphenated, short (`intro-ai`, `python-basics`, `neural-nets`).
- A stage is `done` only when: examples transcribed, exercises attempted, and the user has written something in `notes.md`.
